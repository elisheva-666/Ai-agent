A collection of AI agent projects, from a full-stack production agent to focused exercises exploring core agentic patterns: tool use, human-in-the-loop, CLI agents and retrieval-augmented generation.

## 🎯 [Job Hunter AI](./job-hunter) — flagship project

A smart agent that analyzes a resume and searches dozens of job boards for personalized matches, deciding on its own which search queries to run — with a **human-in-the-loop** step so the user approves sources before the agent proceeds. Full-stack app with a dedicated `backend/` and `frontend/`.
