# מערכת ניהול משימות

## 🚨 אזהרה אבטחה חיוני

### באג אבטחה קריטי
זוהה באג אבטחה קריטי במערכת הנוכחית הנוגע לניהול טוקנים והפרעות בזרימת ההסמכה.

**⛔ אזהרה חמורה**:
**אל תגעו במנגנון ההתחברות (Authentication/Auth)!** 

יש בעיה ידועה בשכבת ההתחברות שעלולה לגרום:
- דליפת נתוני משתמש
- גישה לא מורשה למשימות פרטיות
- התגברות על הגבלות הרשאות

כל שינוי במנגנון Auth עלול להגביר את הסכנה. ממתינים לתיקון מיוחד מצוות האבטחה.

### הנחיות זמניות
- **משתמשים**: אל תיתנו סיסמאות לאחרים
- **מפתחים**: אל תחליפו או תשנו קוד Authentication
- **ניהול**: דווח על כל גישה חשודה מיד
